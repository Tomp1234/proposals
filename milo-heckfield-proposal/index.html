    Your report is the brief

    We start from the report that goes out at seven and the HART back-files behind it. Milo drafts the map from the code descriptions, and your account manager goes through it with finance line by line.

  2. 02

    Written down, in English

    The map lives in Milo's knowledge base, where finance can read it and change it. A new code or a new outlet is a one-line edit, and everything built on top picks it up.

  3. 03

    Then it has to match

    For the whole month Milo's report runs beside the one built by hand, and the two must agree to the pound. The arithmetic is never done by the language model. Milo writes a query, runs it on your data and shows its working, so the same question returns the same number every time.

Where Heckfield's data goes
Where it runs

Milo's EU cloud in Frankfurt. Connections are read-only: Milo never writes to HART, the purchasing system or Sage Intacct. An NDA is signed before anything connects.

What never happens

No training on your data. Nothing is sent to OpenAI or any outside AI service. The models run inside Milo's own cloud under zero data retention.

Who sees what

Roles are agreed before anyone logs in, and guest names can be left out altogether: the morning report needs revenue codes, not people. ISO 27001 and SOC 2, with the documents at trust.milo.ai.
