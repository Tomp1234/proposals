The integration

What we need,
and what we do.

Tixly exposes three open APIs. We have been through what each one gives us and where the revenue data actually sits. Once the keys are in our hands, the rest is our job.

Admin API

Basic auth
The one that matters here
  • Downstream sales information
  • Ticket matrices, allocations and tags
  • Revenue per ticket for analytics
  • Productions and event groups

Event API

API key
Structure and schedule
  • Event details and schedules
  • Sale windows and purchase URLs
  • Ticket availability
  • Country-specific base URL, documented via Swagger

CRM API

Bearer token
Customers and members
  • Member-focused actions and integrations
  • The base layer under Dan's RFM segments
  • Separate authorisation from the Admin API

Based on Tixly's published API documentation and website integration guide. We will confirm scope and endpoints with Darren before anything is connected.
