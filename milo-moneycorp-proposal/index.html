Six questions that come up every time we work with a regulated business. Everything below is checkable at trust.milo.ai.

No. Not by us, and not by the model providers. It is written into the contract rather than sitting on a policy page we can revise later. Your data answers the question in front of it and does nothing else.

Permissions sit under every question and are enforced at the data layer, so Milo cannot read rows the person is not entitled to. A private client analyst asking about corporate margin gets nothing back.

ISO 27001 compliant. SOC 2 Type I compliant, Type II in progress. Independent penetration testing, static application security testing, vulnerability scanning and an internal audit programme.

Five subprocessors, all named publicly: Amazon Web Services for infrastructure, Cloudflare for edge security, ClickHouse for the warehouse, Fivetran for ingestion, Clerk for identity. On the self-hosted options that list gets much shorter, because the components run inside your account.
