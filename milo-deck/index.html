The number · illustrative example

The model never does the maths.

Milo writes the query, runs it on your data and shows it. Calculations run as code, so the same question returns the same number every time, and every figure traces back to the row it came from.

›What was gross margin by region last month?
SELECT region, SUM(revenue - cost) / SUM(revenue) AS gross_margin FROM finance.invoice_lines WHERE invoice_month = DATE '2026-08-01' GROUP BY region
